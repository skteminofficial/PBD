# SAP-TEMIN v2.6.0 — Analisis Menyeluruh Sekolah

Sistem PBD setempat SK Temin yang menukarkan data murid kepada analisis bertingkat:

- murid → profil dan penguasaan setiap subjek;
- kelas → jumlah rekod, menguasai dan belum menguasai;
- subjek → rumusan automatik TP1 hingga TP6;
- tahun dan sekolah → gambaran keseluruhan berdasarkan penapis aktif.

## Cara guna

1. Buka `index.html` dalam pelayar.
2. Import ZIP atau fail Excel SPPB.
3. Lihat kad **Analisis Keseluruhan Setiap Subjek** yang dijana secara automatik.
4. Klik kad subjek, tahun, kelas, TP atau nama murid untuk melihat perincian.

Semua pemprosesan berlaku dalam pelayar. Fail yang diimport tidak dihantar ke pelayan oleh aplikasi ini.

## Terbitkan di GitHub Pages

Muat naik **kandungan** folder ini ke akar repo `PBD` (bukan fail ZIP semata-mata), termasuk `index.html`, folder `css`, `js`, `assets`, dan fail sokongan lain.
